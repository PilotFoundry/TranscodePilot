# Roadmap

The authoritative actionable backlog is [docs/TODO.md](docs/TODO.md). This roadmap
is a short public-facing summary; it is not a promise of dates.

## Current preview — 0.1.x

- SVG/bitmap → PNG/JPEG and MP4/MKV → MP3.
- Local-only processing, source preservation, non-overwriting output.
- Queue, progress, typed/localized errors and recovery.
- Four-language UI and a native macOS shell.
- Release engineering for an ad-hoc, unsigned preview.

## Next

1. Real-volume and TCC acceptance on external storage / Desktop / Downloads.
2. Live VoiceOver and focus-order acceptance.
3. Hosted CI execution with pinned engine versions.
4. Intel and macOS 14 validation, or an explicitly narrowed support matrix.
5. Clean-Mac install acceptance.

## Later, demand-driven

WebP, MOV/M4A/WAV, Finder Quick Actions/Shortcuts, safe embedded SVG images and
named presets. Nothing here is promised without evidence of recurring use.
