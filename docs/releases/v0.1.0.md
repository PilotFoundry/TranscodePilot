# TranscodePilot v0.1.0 — development preview

Local-first SVG/image/audio conversion for macOS by PilotFoundry.

- Release date: 2026-11-13
- Version: 0.1.0 (build 1)
- Platform: macOS 14+ deployment target; local acceptance on Apple Silicon macOS 27
- Status: **development preview**, ad-hoc signed, **not notarized**

## Highlights

- SVG → PNG/JPEG with gradients, filters, masks, clipping, transparency, viewBox and
  physical-unit sizing.
- PNG/JPEG/HEIC → PNG/JPEG with proportional resizing and EXIF orientation.
- MP4/MKV → MP3, first audio track, 128/192/320 kbps.
- Real progress: FFmpeg-derived percentage for MP3, stage progress for bitmap/SVG.
- Local-only processing, source preservation and non-overwriting output.
- Typed, localized errors with Retry / Choose Output Folder recovery.
- English, 简体中文, 繁體中文 and 日本語.
- Native toolbar, menu bar, Dock icon, About panel with version and repository link.

## Assets

- `TranscodePilot-0.1.0-arm64.zip`
- `TranscodePilot-0.1.0-arm64.zip.sha256`

The ZIP is an ad-hoc preview build for Apple Silicon. It does **not** bundle
FFmpeg/librsvg; install them separately:

```sh
brew install ffmpeg librsvg
```

Unzip, move `TranscodePilot.app` to Applications, and approve it in System Settings
if Gatekeeper blocks the unsigned preview.

## Known limitations

- Not signed with Developer ID and not notarized.
- Intel and macOS 14 hardware are not validated; no support claim for them.
- FFmpeg/librsvg are external GPL/LGPL dependencies; no standalone redistribution
  clearance is claimed.
- SVG validation is a coarse local policy, not a general renderer sandbox.
- Live VoiceOver/focus-order, TCC folder prompts and real exFAT/network-volume
  acceptance remain manual.
- Engine memory/CPU rlimits remain a residual hardening item.
